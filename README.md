# Meteorytics

**Atmospheric Data Intelligence**  
*Future Domain:* [meteorytics.fabribrain.com](https://meteorytics.fabribrain.com)

---

## 📌 Visión del Proyecto

Meteorytics es un dashboard web interactivo para la visualización y análisis de datos atmosféricos y meteorológicos. Diseñado con una arquitectura MVC limpia y comprensible en Java puro (JDK `HttpServer` + `HttpClient`) y un frontend ligero en HTML5, CSS3, JavaScript y Chart.js.

---

## 🛠️ Tech Stack

- **Backend:** Java (JDK `com.sun.net.httpserver.HttpServer`, `java.net.http.HttpClient`)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Chart.js
- **Proveedor Externo:** Open-Meteo API (Aislado mediante la interfaz `AtmosphericDataSource`)
